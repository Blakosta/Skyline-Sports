# Skyline Sports — Russian Localization add-on

Separate add-on project for the Russian locale. It does not edit the original mod source or gameplay systems.

The build is performed by GitHub Actions from the `ru-localizer` branch. The output DLL is published as the `Skyline-Sports-Russian-Localization` workflow artifact.

**Important:** locale-key identity and source precedence must still be verified in-game. A successful compile alone does not prove that the game applies every translation over the original mod's English source.
